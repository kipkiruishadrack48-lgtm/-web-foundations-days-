# Day 8 Reflection

The most difficult concept in this course was system design, especially understanding how different components work together to handle many users and requests. Concepts such as databases, caching, load balancing, and scalability were challenging at first. I overcame this by studying the examples, practising the assignments, and following the system design steps one at a time. Breaking complex problems into smaller tasks helped me understand them better.

Based on the feedback I received on my previous assignments, I would improve my capstone by making the architecture more detailed and explaining how information moves between different components. I would also improve my diagrams and explain how the system handles failures and high traffic. This would make my design clearer, more complete, and easier for another developer to understand.

Next, I want to learn more about backend development, database management, API development, and cloud computing. I also want to practise building real applications and connecting their frontend and backend. My goal is to become a better software developer by applying the concepts I have learned to practical projects.
