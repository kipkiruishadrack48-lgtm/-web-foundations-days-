
# Day 8 Reflection

The most difficult concept in this course was system architecture and understanding how different components work together to handle many users at the same time. At first, I found it challenging to understand load balancers, caching, databases, and how to prevent two users from booking the same seat. I overcame this by studying the examples, following the assignments step by step, and practising how to design systems using diagrams and simple explanations.

Based on the feedback I received on my TicketHub capstone, I would improve the architecture section by including a complete diagram showing the CDN, waiting room, load balancer, application servers, cache, database, and payment service. I would also explain how each component works together during a popular concert sale. Another improvement would be adding clear trade-off discussions, especially consistency versus latency and relational databases versus NoSQL databases. This would make my design more complete and easier to understand.

Next, I want to learn more about backend development, database management, APIs, cloud computing, and system scalability. I also want to improve my practical coding skills by building real projects and testing how applications perform under heavy traffic.
